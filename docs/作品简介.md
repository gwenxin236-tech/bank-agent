# 澜银行 AI 智能体作品简介

## 报名系统提交正文（T15，175 个非空白字符）

澜银行AI智能体以自然语言简化银行操作，让AI负责理解与规划、平台策略决定权限、工具结果提供事实。原型采用意图识别、六领域Agent协作和DAG编排，支持查询、转账与订阅管理；绿色自动、黄色确认、红色演示强验证，并提供防注入、审计、熔断、中断回退和本地人工接管。默认离线运行，使用模拟银行数据，不连接真实银行；可选大模型仅辅助意图识别，不能授权交易。

正文已单独保存为 `submission/作品简介.txt`，报名时只复制正文。计数口径为 Unicode 非空白字符（汉字、英文字母、数字、标点均计入），共 175，未计标题或换行。原 DOCX P25 要求 200 字以内，未规定平台算法；平台最终显示字数尚未核对，不能把本地计数说成系统已验收。

## 详细版（备用，不提交，用于答辩或介绍材料）

澜银行 AI 智能体把"找入口、填表单、反复确认"的传统手机银行流程，重构为可解释的自然语言任务。用户可以说"查余额""分析账单""给妈妈转 200 元"或"查订阅"。当前离线模式使用规则意图识别与固定任务模板，可选大模型仅抽取受限意图/实体；六域是基于平台快照的只读分析模块，固定 Supervisor 核对证据、保留冲突，不是六个自主联网模型。执行仍须平台三色权限、确认和演示强验证，结果来自 Mock 工具。作品以 Web、本地终端、持久 DAG、审计和接管队列展示工程能力；已接入本地RAG、独立重排、OCR、自建Web坐席及可选密码＋TOTP；Fineract仅处理本地虚构资金。持牌银行、官方IM/客服和生产IAM未接入，完整AI离线镜像尚未按提交日源码重建。
