# 大模型接入说明

## 当前状态

项目默认运行在规则解析模式，不要求 API Key，也不依赖第三方 Python SDK。这样可以保证竞赛现场离线可运行。`app/llm_adapter.py` 提供可选的 OpenAI Chat Completions 兼容 HTTP 适配器；配置后，大模型只负责把自然语言转换成受限的 `intent + entities` 协议。

## 配置

```bash
export LLM_PROVIDER=siliconflow
export LLM_API_KEY="$(python3 -c 'import getpass; print(getpass.getpass("LLM API Key: "))')"
export LLM_MODEL="Qwen/Qwen3-Omni-30B-A3B-Instruct"
export LLM_BASE_URL="https://api.siliconflow.cn/v1"
export LLM_TIMEOUT_SECONDS=20
export VOICE_ENABLED=1
unset BANK_AGENT_OFFLINE
./run.sh
```

也兼容 `OPENAI_API_KEY`、`OPENAI_MODEL`、`OPENAI_BASE_URL`。同名 `LLM_*` 优先（显式空字符串也会覆盖别名）；未设置密钥或模型时，服务自动回退规则解析。`LLM_PROVIDER` 是展示标签，不会切换 SDK 或自动选择域名。

以上命令在仓库根目录、**启动服务的终端 A** 执行，修改变量后需要重启旧服务。`run.sh` 不会自动加载 `.env`，不要只编辑文件而未把变量导入进程。不要开启 `set -x`，不要把密钥放进代码、截图、录屏、聊天或 Git。`BANK_AGENT_OFFLINE=1` 会强制规则模式，在线验证前须取消该变量。

`LLM_TIMEOUT_SECONDS` 未设置时默认 8 秒，示例设为 20 秒；合法范围为有限数值 `0 < t <= 60`。`abc`、空字符串、NaN、无穷大、零/负数、超范围值均使模型配置失效，**不抛异常、不发请求，继续走规则**。超时是 urllib 网络操作超时，不承诺覆盖 DNS 等全部阶段的生产端到端时限。

## 一键验证：证明“本次走了模型”

前提：终端 A 已按上节配置并启动服务，使用本项目的虚构演示数据。在仓库根目录另开终端 B，直接复制这一条命令（本终端不需要 Key）：

```bash
python3 scripts/verify_llm.py
```

端口不是 8090 时追加 `--url http://127.0.0.1:<本地服务端口>`。该参数是**本地银行演示服务地址，不是模型 API 地址**；脚本只允许本机地址，不转发演示会话到任意远程服务。

脚本使用现有演示会话提交固定的“请查询我的账户余额”，随后按返回的同一 `trace_id` 查询审计。它不调用确认、验证码或取消接口；请仅在虚构账户环境运行。判断条件：查询实际完成、结果来自 `get_balance`，且本次审计证据同时为：

```json
{
  "source": "llm",
  "attempted": true,
  "accepted": true,
  "reason": "accepted"
}
```

全部满足才输出 `status: PASS` 并以 **0** 退出。缺 Key、网络不通、响应非法、模型误判意图、只有规则查询成功等均输出 **FAIL / 退出码 2**。FAIL 不代表银行离线功能损坏，而是“本次在线模型验证没有通过”。脚本输出 trace 和原因枚举，不打印 Key、用户余额、模型原文或上游异常原文。

### 日志 / 接口证据在哪

- `GET /api/v1/audit/events?trace_id=<本次 trace>`，带 `Authorization: Bearer demo-user-session`，查看 **`parser.result`** 事件的 `payload`：包含 `source/attempted/accepted/reason/intent/plan_id`。
- Web 页头“服务记录”图标 → 审计链回放 → 输入脚本输出的 trace → 查找 `parser.result`。事件进入现有审计哈希链，沿用本次计划的身份与 trace。
- `/api/capabilities` 的 `llm_enabled/model_mode` **只表示配置状态，不是调用成功证据**；HTTP 200、余额查询成功也不能替代上述事件。
- 转账、改密、卡片操作等本地安全优先路径不调用模型，记录 `local_priority`；D4 的“功能演示”走独立离线入口，记录 `feature_demo`。验证模型请用本节固定查询，不用转账或 D4 指令。
- 进入解析前即被注入/泄露规则拦截的请求没有 `parser.result`，应查看对应阻断事件，不能冒称模型已调用。

### 常见结果与排查

| `reason` | 含义 | 人工处理 |
|---|---|---|
| `disabled` | 缺 Key/模型，或强制离线 | 检查终端 A 的环境；不要直接打印 Key |
| `invalid_config` | 非法超时、URL 等配置 | 修正数值和服务基址并重启 |
| `timeout` | 网络操作超时 | 检查供应商状态；合法范围内调整超时后人工重试 |
| `network_error` | DNS、连接、TLS 或断流失败 | 核对可信网络与网关；不要关闭证书校验 |
| `http_error` | 上游拒绝或服务异常 | 到供应商控制台检查密钥权限、模型可用性、余额和限流 |
| `invalid_json` / `invalid_response` | 响应不是合法 JSON 或不符合 Chat Completions 信封 | 检查模型/网关协议，不把浏览器聊天地址当 API |
| `schema_rejected` | 非允许意图或实体/金额类型不合规 | 改用符合受限结构化输出要求的模型，不放宽权限和金额校验 |
| `response_too_large` | 响应超过 64 KiB | 检查网关/模型返回是否异常 |

模型请求不自动重试。回退只调用原有规则解析器，后续仍受 PolicyEngine、确认、认证和工具白名单约束。

## 需要我人工提供什么

本项目选择硅基流动的 OpenAI 兼容接口。密钥由负责人本人申请并在本机配置，不要发给团队成员、AI 助手或写入 Git。只使用虚构演示数据。

| 环境变量 | 本次建议取值 | 人工获取方式 | 现场是否必须 |
|---|---|---|---|
| `LLM_PROVIDER` | `siliconflow` | 直接填写；语音适配器也检查此标签，避免误用其他厂商 Key | 在线语音必须 |
| `LLM_API_KEY` | 自己账号的真实 Key | 登录 [硅基流动控制台](https://cloud.siliconflow.cn/)，在 API 密钥页面创建；本人核对授权、余额和用量 | 离线不需要 |
| `LLM_MODEL` | `Qwen/Qwen3-Omni-30B-A3B-Instruct` | 控制台模型广场搜索完整 ID，确认账号可调用 | 在线意图理解需要 |
| `LLM_BASE_URL` | `https://api.siliconflow.cn/v1` | 官方 API 基址；不是 `/me/models` 网页地址 | 在线意图理解需要 |
| `VOICE_ENABLED` | `1` | 明确启用云端语音；默认关闭 | 真实语音转写需要 |
| `LLM_TIMEOUT_SECONDS` | `20` | 网络操作超时；语音目前独立固定为 20 秒 | 可选 |

操作：登录并完成账号必要验证 → 核对服务条款/数据处理政策 → 创建 Key → 设置可用的预算与用量告警 → 按本文启动命令安全输入 → 执行 `python3 scripts/verify_llm.py` → 现场语音验证 → 控制台核对用量。本文不代为开通、付费或处理真实 Key。

### 为什么选 Omni + 独立语音转写

以下为 **2026-09-21 公开价格页核对值**，2026-09-22 整理；不是报价承诺，也不是本项目的实测质量排名。启用前以本人控制台可用模型、实时计费和余额为准。

| 模型 | 公布的输入 / 输出价（人民币 / 百万 token） | 适用判断 |
|---|---|---|
| Qwen/Qwen3-VL-8B-Instruct | ¥0.50 / ¥2.00 | 只做图文时更省钱；官方能力表不支持音频 |
| Qwen/Qwen3-VL-30B-A3B-Instruct | ¥0.70 / ¥2.80 | 图文/视频；与 Omni 表价相同，但不支持音频 |
| **Qwen/Qwen3-Omni-30B-A3B-Instruct** | **¥0.70 / ¥2.80** | **本项目推荐**：官方能力表覆盖图像/音频/视频，给后续多模态留余地 |
| Qwen/Qwen3-VL-32B-Instruct | ¥1.00 / ¥4.00 | 本轮未发现必须支付更高价格的业务理由；仍须按本项目任务评测 |
| Qwen/Qwen3.5-35B-A3B（输入 <128K） | ¥0.40 / ¥3.20 | 输入便宜但输出更贵；默认思考模式，当前适配器未调思考开关，不作为此次首选 |

ASR 单独使用 **`FunAudioLLM/SenseVoiceSmall`**，官方公开页当前标为免费；不保证账号额度、可用性及未来价格。它负责把声音变成文字，Omni/离线解析器负责理解文字。音频不直接决定权限，且可先检查“500 / 5000”“妈妈 / 爸爸”等易混淆实体。当前没有实现图片/视频上传，也没有将原始音频直接送入 Omni；**配置一个多模态模型不等于完成所有多模态通道**。

按 Omni 一次纯文本输入 1000 token、输出 200 token 估算：约 **¥0.00126 / 次，1000 次 ¥1.26**。这是理想文本预算，不含重试（本项目不自动重试）、服务附加费，也不代表图像/音频计量。实际模态 token 及账单以供应商为准。语音合成不是本轮需求；如后续选 CosyVoice2，其公开价按 UTF-8 字节而非 token，不能混算。

依据：[官方价格表](https://siliconflow.cn/pricing)、[多模态能力表](https://docs.siliconflow.cn/docs/userguide/capabilities/multimodal-vision)、[转写接口](https://docs.siliconflow.cn/docs/api/audio-transcriptions-post)。控制台模型页需要本人登录；本轮未用真实 Key 调用模型，因此不宣称真实链路、时延、方言或金融实体识别率已实测通过。

**现场演示不必须有 Key**。保留规则模式作为主备方案：`BANK_AGENT_OFFLINE=1 ./run.sh`；无 Key 回归可运行 `env -u LLM_API_KEY -u OPENAI_API_KEY PYTHONPATH=app python3 -m unittest discover -s tests -v`。自动化测试使用本地模拟模型/故障注入，不访问付费模型。通过模拟器不等于真实供应商验证通过；真实 Key 的 PASS 需本人执行上述步骤获得。

## 语音输入：现场验证步骤

1. 停掉旧服务；在仓库根目录执行本文“配置”命令。`VOICE_ENABLED=1`、`LLM_PROVIDER=siliconflow`、`LLM_API_KEY` 必须有效，且不能设置 `BANK_AGENT_OFFLINE=1`。Key 仅在服务端进程，不送浏览器。语音目标固定为可信硅基流动 HTTPS 地址，不接受用户指定 URL，不跟随重定向。
2. 打开 `http://127.0.0.1:8090`，点击 **说一说**。本机或 HTTPS 才可正常申请麦克风权限；局域网明文 HTTP 通常不支持。先阅读外发提醒，勾选本次同意，再点击 **开始录音**。浏览器权限弹窗选择允许。
3. 说“帮我查一下账户余额”，点击 **完成录音**（最长 30 秒自动停止）；浏览器在内存中生成单声道 16kHz PCM WAV，上传至 `POST /api/v1/voice/transcribe`。服务端只接受合法 WAV（最大 2MiB / 30秒），要求演示会话和 `X-Audio-Consent: yes`。
4. 看到文字出现在输入框，**此时尚未提交银行任务**；修改误识别字后点击发送。查询走原网关→解析→策略→工具；若说“给妈妈转5000元”，必须先出现确认/强认证，而不是立刻扣款。
5. 查验语音证据：浏览器 Network 的转写响应应有 `ok: true`、`source: siliconflow_asr`、独立 `trace_id`。用同一演示会话查询 `/api/v1/audit/events?trace_id=...`，应有 `voice.transcribed`，记录发起人/设备/状态，**不记录原始音频或转写文字**。之后点击发送是第二个 HTTP 请求，有自己的银行任务 trace；可用 `parser.result` 判断本次是模型还是规则，不以页面“配置了模型”作为成功证据。
6. 取消录音不上传，退出页面释放麦克风；识别失败不编造文字，不自动重试/发送，继续打字。缺 Key / 强制离线时明确提示语音不可用，银行文字演示不受影响。没有捆绑离线语音模型，也不悄悄改用浏览器第三方识别服务。

可先复制以下命令只检查**配置可用性**（不代表已识别成功）：

```bash
curl --fail --silent http://127.0.0.1:8090/api/v1/voice/capabilities
```

真实录音属于生物/个人信息风险场景：本应用不落盘、不在审计保存声音；这不代表供应商不保留数据。演示限虚构内容，真实客户语音外发前必须完成隐私评估、供应商合同、数据地域/保留删除审批，并替换公开演示 token 为真实 IAM。浏览器目前使用标准 Web Audio 采集（无外部 JS 依赖），生产可替换为 AudioWorklet / 流式私有 ASR，并增加全链路预算、配额与超时治理。

## 安全边界

1. 模型不能直接调用银行工具。
2. 模型不能决定风险等级、额度、是否需要强验证。
3. 所有金额使用整数分，服务端重新核算。
4. 模型输出必须是 JSON，并通过字段白名单和类型校验。
5. API 超时、非法 JSON 或服务不可用时回退规则解析。
6. 真实客户数据必须先脱敏，不得把卡号、余额、流水、证件号发送给外部模型。当前适配器只发送用户文本，不附带账户查询结果；它不保证自动识别并脱敏任意自由文本，因此在线演示仅可输入虚构数据。真实数据外发前须另行接入审查与脱敏网关。
7. 工具结果是余额、交易号和业务状态的唯一事实来源。

## 生产替换点

- 使用企业模型网关或私有化模型；
- 引入 JSON Schema 版本管理、模型评测和审计；
- 为模型请求增加超时、限流、预算和故障转移；
- 对 prompt injection、敏感信息泄露、过度代理权限做红队评测；
- 将模型调用与银行核心调用分离，禁止共享高权限凭证。
