# **P05 音频证据与录音生命周期**

## **1. 目标与边界**

### **1.1 本批能力**

- **需求层级**：P05是团队工作表的自定平台目标，不是新增赛题硬要求。复用语音输入、三色权限和审计，不新增领域Agent接口或银行执行工具。
- **离线模式**：录制虚构演示音频并计算本机摘要，不外发、不转写、不填交易草稿；在线识别须本次明确云同意，仍只填文字，由用户核对并自行发送。
- **证明范围**：SHA256只证明指定字节的一致性，不识别人、不鉴定录音真伪或时间，不替代实名/强认证、签名或不可抵赖证明。

## **2. 数据与接口**

### **2.1 三种不同摘要**

| 字段 | 精确字节范围 | 作用 |
| --- | --- | --- |
| upload_sha256 | HTTP请求体收到的全部WAV字节，含文件头与元数据 | 与上传文件复核，不代表重采样前的硬件原始流 |
| pcm_sha256 | 解码PCM样本字节，s16le/单声道/16kHz | 比较样本；不同容器元数据可得到相同PCM摘要 |
| normalized_wav_sha256 | 由该PCM重封装的标准WAV全部字节 | 与实际交给ASR的去元数据文件对应 |

- **格式**：最多2MiB，RIFF长度精确匹配、合法分块、单一fmt/data、16位PCM单声道16kHz、1—480000帧，最长30秒。返回各字节数、帧数和向下取整的整数毫秒；格式/截断/额外尾部/超限均拒绝。
- **转换**：浏览器已有转换先生成16kHz WAV，服务端不再重采样，只提取PCM并重封装。原始硬件流未上传，不能声称已计算其摘要。只改元数据可能仅改变上传摘要，改PCM样本会改变内容摘要。

### **2.2 同意与语音接口**

- **查询**：GET `/api/v1/voice/capabilities`新增`evidence_enabled/audio_evidence_schema/application_audio_persisted/offline_mode`；原`enabled`仍只表示云ASR可用，默认离线也可生成证据。
- **上传**：原POST `/api/v1/voice/transcribe`接受WAV二进制及受信会话。`X-Audio-Consent: yes`表示本次本机处理同意；在线配置及`X-Audio-Cloud-Consent: yes`同时满足才调用ASR。缺云同意或离线时返回`mode=local_evidence_only`，没有转写文本、来源令牌或业务计划。
- **结果**：合法音频返回`audio_evidence/trace_id`，所有分支明确`business_executed=false`；ASR成功另给`voice_source_token/requires_text_review`。失败不自动重试，不回传密钥或上游异常细节。
- **兼容变化**：旧客户端仅发原同意头时现在只计算本机证据；云识别必须新增云同意。页面显示实际模式，撤回勾选会停止录音并取消等待。HTTP同意记录是客户端声明，不是经公证的真人同意或生产身份认证。

### **2.3 人工复核与业务trace**

- **令牌**：只缓存用户、设备、来源trace、三个摘要和到期时间，容量64条，有效期300秒，不保存音频或转写文本。跨用户/设备、过期、未复核和重放拒绝；锁保证并发只消费一次。
- **发送**：核对后由用户点击发送，原POST `/api/chat`带`voice_source_token`及严格布尔`voice_reviewed=true`。验证后仍走原Supervisor、权限、确认与必要认证；OCR和语音来源冲突时拒绝。
- **关联**：`voice.linked`记录来源trace及三个摘要。允许用户编辑文字，因此它表示输入来源，不证明最终文字逐字等于录音，更不把ASR或摘要当BankFact/支付授权。
- **审计**：`voice.evidenced/voice.transcribed/voice.rejected`记录同意、云同意、外发尝试、摘要和留存方式，不记录录音或转写全文。服务端生成且格式验证通过的摘要/来源标识用专用内部类型保留原值，避免普通数字脱敏误损；普通JSON同名字段仍脱敏，不放宽用户输入。

## **3. 留存与删除**

### **3.1 生命周期表**

| 数据 | 留存位置/时限 | 清理与边界 |
| --- | --- | --- |
| 浏览器采样副本 | 当前录音内存，最多30秒 | 编码后、取消或撤回同意时覆盖数组并清空引用；停止麦克风、关闭AudioContext |
| 浏览器标准WAV Blob | 当前fetch内存 | 完成/失败/取消后释放应用引用；不写localStorage、IndexedDB或录音文件 |
| 服务端WAV/PCM/multipart | 当前HTTP/ASR调用内存 | 校验/调用结束释放引用，不创建音频文件或数据库音频字段；读取最多10秒、ASR原有20秒超时 |
| 来源令牌元数据 | 进程内存，300秒逻辑期限/容量64 | 消费即删，后续访问清理过期项，重启全部失效；没有到时物理擦除承诺 |
| 摘要与同意审计 | 既有演示SQLite审计链 | 随原审计保存；取消不篡改既有链，不虚构法定保留天数，不提供删链绕过入口 |
| 已发送的标准WAV | 供应商系统 | 取消无法撤回已送达数据；未接供应商删除接口，不宣称云端已删除 |

- **清理边界**：覆盖的是应用可变采样数组。Python不可变bytes、Blob、GC、系统缓冲不提供物理安全擦除保证；摘要也不等于匿名化，访问仍受原审计主体权限约束。
- **不设录音删除API的原因**：应用没有持久音频对象可供下载/删除，只留下最小审计元数据。未来若引入录音文件，须重新设计授权、期限和实际删除验收，不能沿用本批结论。

### **4.2 操作与复现**

- **离线演示**：点语音按钮，确认“离线音频证据模式”，同意后录制虚构内容，完成显示摘要前12位。原输入不变、无业务计划；审计保存完整64位，界面短摘要不能代替完整校验。

## **5. 真实麦克风、云ASR与供应商能力扩展（2026-10-24）**

### **5.1 本次真实验收结果**

- **授权与操作**：仅固定短句“这是语音识别验收，仅生成草稿，不办理业务”，最多10秒、最多2次；用户在原生麦克风页面录制、试听、勾选后手动发送，核对识别文字后保存结束。工具`scripts/voice_acceptance.py`复用页面WAV编码和正式语音处理器，只在隔离数据库运行，不办理银行业务。
- **实际结果**：`data/verification/p05-real-20261024/physical-cloud.json`记录最终录音6570毫秒、105130帧、210304上传字节；SiliconFlow SenseVoiceSmall返回HTTP200，请求追踪头回显一致；固定短句18字符、编辑距离0、CER=0。累计2次调用，先前一次结果未单独保留，不将两次都表述为准确率满分。
- **证据复核**：`real-verification.json`的13项检查通过，含本地与上传的三个摘要一致、时长/格式、人工核对、无录音落盘及无银行业务。真实麦克风为用户操作与确认的证据，不是硬件认证；单句成功也不代表噪声、多口音、长语音或泛化准确率。
- **当前回归**：扩展后音频专项17项通过，见`data/verification/p05-real-20261024/voice-final.log`；与P06联合全量回归及最新镜像见《P06动态DAG提案与监督审核》第4.3节和`docs/验收摘要.json`。不以基础批674项替代当前验收。

### **5.2 供应商处理与删除边界**

- **追踪**：`SpeechAdapter.transcribe`为外发请求生成`asr_`加32位十六进制ID，发送`X-Trace-Id`并核对响应`x-siliconcloud-trace-id`。审计只保留可信请求ID、状态码和是否回显一致，不写原始音频/转写全文。接口依据：[官方ASR文档](https://docs.siliconflow.cn/docs/api/audio-transcriptions-post)。
- **实际能力**：未找到逐条ASR录音删除接口的官方文档证据；[音色删除接口](https://docs.siliconflow.cn/docs/api/audio-voice-deletions-post)删除的是自定义音色URI，不能拿来声称已删除识别录音。`provider_retention_info()`明确`record_delete_api=NOT_DOCUMENTED/deletion_verified=false`。
- **政策与申请**：[隐私政策](https://docs.siliconflow.cn/docs/legals/privacy-policy)声明推理业务数据的临时处理/处置，另有日志留存；核对的政策版本为2026-07-30。政策声明不等于逐条擦除回执。页面展示处理说明，可调用`POST /api/v1/voice/deletion-request`，在本人、设备、来源和审计链核对后生成发往官方联系邮箱的申请草稿；状态始终`NOT_SENT`，本批没有发送邮件或取得供应商删除证明。
- **异常边界**：没有外发的本地记录明确返回`LOCAL_ONLY_NO_PROVIDER_UPLOAD`；历史记录没有可核验请求ID时拒绝伪造申请。异主体/设备、损坏审计链均拒绝。申请草稿不含音频、转写全文或密钥，取消本地请求不能撤回已送达供应商的数据。
