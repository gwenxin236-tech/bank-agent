## 3 语音外发审计

本节补齐L1审计可追溯要求与L3语音隐私设计；不将语音结果作为银行回执或生产认证证明。代码：`app/banking_agent.py:4797`、`app/tts_output.py:34`；专项测试：`tests/test_pr1_integration.py:14`。

- **身份与trace：** 使用现有HTTP身份判定，服务端生成trace，绑定已核验actor/device；身份拒绝不信任请求声称的用户。音频成功响应在`X-Trace-ID`返回trace，错误JSON也包含trace。
- **事件顺序：** `tts.requested` → 参数/同意/离线/并发检查 → `tts.outbound` → 单次供应方调用 → `tts.completed`或`tts.failed`；拒绝为`tts.rejected`。到达语音处理器的身份拒绝留最小事件，外层身份服务和HTTP限流维持原机制。
- **外发前审计：** requested或outbound无法持久化时，不启动供应方进程；合成完成后审计失败返回503，不自动重试供应方。资金工具不进入该路径。
- **最小元数据：** 固定供应商标识、同意、可信身份、脱敏文本SHA256与字符数、外发尝试、安全结果码；不保存正文、音频、Authorization或供应方原始异常。审计中的retention指原始正文/音频仅存请求内存；审计元数据按既有AuditStore持久化。
- **外发事实边界：** `tts.outbound`记录已授权尝试，不代表供应商收到或删除资料，`provider_delivery_verified`保持false。所有语音响应不办理银行业务。
- **摘要完整性：** 沿用P05的服务端专用标识类型，仅为内部计算的`text_sha256`保留完整64位摘要；用户提交的同名普通字符串仍按原数字规则脱敏，不启用全局hash字段免检。

| 情况 | 处理与证据 |
|---|---|
| 未同意/非法参数 | 400，无供应方调用，有拒绝事件 |
| 语音处理器身份拒绝 | 403，不信任未核验actor/device，不外发 |
| 离线/未启用/缺少可选依赖 | 503，不外发；页面文字与本机/预置提示仍可用 |
| 合成并发槽已满 | 429，不获取或释放其他请求的槽，不重试 |
| 供应方失败/超时 | 503，安全原因码，单次尝试，不记录原异常文本 |
| 外发前审计故障 | 503，无供应方进程调用 |
| 已开始合成后审计故障 | 503，不重新调用供应方，不声称银行业务完成 |

## 4 离线与依赖边界

使用PR提供的44个公开短语音片段，校验内容和SHA256；预置提示不需要实时联网合成。其余内容可使用浏览器报告的本机普通话。自动播放策略、真实扬声器效果和目标用户体验仍需实际设备验证。

在线TTS默认关闭，离线开关优先。本批未安装或升级edge_tts，未运行`build_speech_prompts.py`的联网生成路径，未请求Microsoft或付费云API；供应方路径仅用Mock进程返回值验证。启用真实供应方须另行完成依赖批准、数据范围授权和实际联调，不把本地Mock通过称为供应方验收。
