# 中文自然语音播报

> 成员历史交接资料：本文件来自PR #1的原提交81ea8acd，文中验收数字、源码指纹与环境描述仅属于当时版本。当前集成范围及965项本地分组验收见[PR1集成与验收](PR1集成与验收.md)。本次已规范成员姓名；原始文本仍可从原提交查阅。供应方或依赖的旧环境授权不构成本项目当前安装、联网或生产验收授权。


面向个人银行用户和长辈，默认候选为普通话“晓晓”，备选“云希”；语速默认 -8%，可选择舒缓、标准和稍快。音色是否符合用户偏好需实际试听，不以代码测试代替听感评价。

## 已准备的接入

- 输出独立于录音转写和银行执行。播放器只调用 `/api/v1/voice/synthesize`，不能确认交易。
- 显示与帮助设置增加音色、语速、联网开关、试听和停止。联网开关、音色、语速及自动播报偏好保存在本机，刷新后恢复；云端始终隐藏数字、账号、验证码及常见密钥，服务端再次处理。
- 仅普通话本机音色作为离线选项，不默认调用浏览器可能提供的其他远程音色。
- 分句播放本机语音，停止旧请求、忽略迟到响应、释放音频对象；切换显示模式不重复播报业务。
- 播报工具结果及身份验证提示，避免办理完成后仍朗读旧计划。错误只影响声音，不重试银行业务。
- 云端音频仅在内存中，当前应用不保存业务音频或全文；供应商的处理不等于已获得删除凭证。

## 可选依赖及启用

`requirements.txt` 保持原样。默认 TTS 关闭且 `BANK_AGENT_OFFLINE=1` 禁止联网。候选社区包 `edge-tts==7.3.1`（LGPLv3）通过 Microsoft Edge 在线服务合成，不需要 API 账号；不是 Azure 商用服务承诺。原成员交付记录曾描述其开发环境的安装和试听授权；本项目本次仅完成Mock验收，未安装该依赖、未请求真实供应方。启用前须取得本项目的依赖及具体数据外发授权；以下命令只作为待审批示例。

安装到项目隔离目录（不能把这些包提交到仓库）：

```powershell
python -m pip install --target .qa-tools/tts-site edge-tts==7.3.1
$env:PYTHONPATH = (Join-Path $PWD '.qa-tools/tts-site')
$env:TTS_ENABLED = '1'
$env:BANK_AGENT_OFFLINE = '0'
python app/banking_agent.py
```

网页“显示与帮助设置”中启用联网语音后试听。音频生成最多22秒，最多2个并发、600字符，服务端仅允许两种音色和四档语速；无文件参数、任意地址或 shell 拼接。没有模块时仍能启动原有离线项目。正式银行部署应替换成经批准的语音服务及数据处理协议。

## 选择依据

- [edge-tts 项目文档](https://github.com/rany2/edge-tts)：在线音色选择、语速与音调控制、无需单独运行 Edge。
- [Microsoft 普通话音色列表](https://learn.microsoft.com/azure/ai-services/speech-service/language-support?tabs=tts)：普通话神经语音；Azure 与 Edge 可用目录可能不同，须以实测为准。
- [ElevenLabs 中文合成说明](https://elevenlabs.io/docs/overview/capabilities/text-to-speech)：中文及原生口音选择。本次尝试 Jill，但免费生成通道繁忙，没有生成或扣费。
- [SiliconFlow 语音合成](https://docs.siliconflow.cn/docs/userguide/capabilities/text-to-speech)：CosyVoice2 的 anna、claire 等候选，需要 API 账号。原交付方案未采用该供应方；本项目既有SiliconFlow配置不等同于TTS模型已启用或通过验收。

## 简短播报修订

按用户要求，点击快捷功能只播报按钮名称，例如“查余额”“看消费”“转一笔钱”“看自动扣费”。成功返回的详细说明保留在页面，不再追加长句。确认、身份验证、失败或未知结果只播报简短提示；不根据未知结果宣称成功。切换显示模式不触发额外播报。试听文案同步改为“看消费”。Node测试执行实际发送函数，验证只播报一次且原业务请求不变。

## 刷新后音源回退修复（2026-11-01）

发现原因：原联网开关只存于DOM，刷新页面即恢复未勾选，导致自动播报重新使用本机音色。现将四项偏好保存在 `bankSpeechPreferences.v1`，只保存开关、白名单音色和语速，不保存播报内容、音频或银行数据。新浏览器仍须启用联网语音；此前选择会在刷新和重新打开后恢复，用户显式关闭也会保留。

联网服务故障时保留已选音源并提示，不自动回退到本机声音；即便服务不可用，仍可手动关闭联网语音。存储受限时明确提示“仅本次页面有效”。Node覆盖非法存储、显式关闭和偏好恢复；浏览器用例实际刷新页面、核对音色/语速/自动播报开关，并验证云端失败不调用本机发声。真实页面已启用晓晓并验证刷新后保留设置及联网试听。

## 点击延迟与多音字修复（2026-11-01）

原点击链每次都请求在线合成，并启动独立Python工作进程；短按钮词还可能被引擎错误断词。本次给21条固定功能名/办理短提示准备晓晓、云希两种音色，共42段音频，约725KiB，存放在 app/static/speech-prompts.json。网页提前加载并准备音频，点击走本地Blob播放，不调用合成接口；正文、姓名、金额、账号及其他动态内容不加入音频包或缓存。自动播报开关、停止、过期响应隔离以及原确认链保持有效。

精确词条映射：按钮“查余额”播报“查询余额”，按钮“转一笔钱”播报“转账”。仅替换完整固定词条，不进行全局单字替换、谐音字拼凑或把拼音交给引擎朗读。其他功能仍只播报功能名。两种音色均采用相同明确文案；音色和四档语速继续尊重用户选择，变速时启用preservesPitch。该处理针对本项目已列出的固定词条，不声称任意中文输入的所有多音字已获得人工发音验收。

本地音频包是公开UI素材，随源码发布，与禁止保存客户业务音频的边界不同。常用提示离线也可使用自然音色，无需安装edge-tts或打开联网合成。音频包缺失时仍遵循用户选择：已开启联网的使用在线合成，否则使用本机普通话；词条映射在两条路径上都生效。在线合成失败不静默切换到本机引擎。未准备完的音频被停止后不会迟到播放；快速再次点击也不会因上一次被停止的去重记录而无声。

重建素材仅用于开发：将已批准的edge-tts==7.3.1置于隔离PYTHONPATH，再运行 `python scripts/build_speech_prompts.py`（有需要时传入已有代理的 `--proxy`）；仅发送脚本中硬编码的公开短语。未增加强制运行依赖，不在银行请求路径生成或下载新素材。每段素材包含SHA-256，回归检查词条完整性、哈希和真实MP3解码。

本机专项实测点击至浏览器playing事件为311、532、19、48毫秒，覆盖两音色的“查询余额”和“转账”；四次点击均为0次合成请求，0次本机TTS调用。42段音频均可解码，最长开头静音约318毫秒。以上是本机单次浏览器测量，playing事件不等同扬声器声学起音，不作为所有设备的延迟保证。报告保存在 data/verification/speech-latency-preload.log。

参考：[edge-tts上游](https://github.com/rany2/edge-tts)说明不支持任意自定义SSML；本次没有依赖无法使用的注音标签。[MDN preservesPitch](https://developer.mozilla.org/en-US/docs/Web/API/HTMLMediaElement/preservesPitch)说明变速保调的播放器行为。
