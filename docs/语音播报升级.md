# 中文自然语音播报

面向个人银行用户和长辈，默认候选为普通话“晓晓”，备选“云希”；语速默认 -8%，可选择舒缓、标准和稍快。音色是否符合用户偏好需实际试听，不以代码测试代替听感评价。

## 已准备的接入

- 输出独立于录音转写和银行执行。播放器只调用 `/api/v1/voice/synthesize`，不能确认交易。
- 显示与帮助设置增加音色、语速、联网开关、试听和停止。联网同意仅本页有效；云端始终隐藏数字、账号、验证码及常见密钥，服务端再次处理。
- 仅普通话本机音色作为离线选项，不默认调用浏览器可能提供的其他远程音色。
- 分句播放本机语音，停止旧请求、忽略迟到响应、释放音频对象；切换显示模式不重复播报业务。
- 播报工具结果及身份验证提示，避免办理完成后仍朗读旧计划。错误只影响声音，不重试银行业务。
- 云端音频仅在内存中，当前应用不保存业务音频或全文；供应商的处理不等于已获得删除凭证。

## 可选依赖及启用

`requirements.txt` 保持原样。默认 TTS 关闭且 `BANK_AGENT_OFFLINE=1` 禁止联网。候选社区包 `edge-tts==7.3.1`（LGPLv3）通过 Microsoft Edge 在线服务合成，不需要 API 账号；不是 Azure 商用服务承诺。用户已于本轮明确批准安装及联网试听；安装范围仅为项目隔离目录。

安装到项目隔离目录（不能把这些包提交到仓库）：

```powershell
python -m pip install --target .qa-tools/tts-site edge-tts==7.3.1
$env:PYTHONPATH = (Join-Path $PWD '.qa-tools/tts-site')
$env:TTS_ENABLED = '1'
$env:BANK_AGENT_OFFLINE = '0'
python app/banking_agent.py
```

网页“显示与帮助设置”中启用联网语音后试听。音频生成最多22秒，最多2个并发、600字符，服务端仅允许两种音色和四档语速；无文件参数、任意地址或 shell 拼接。没有模块时仍能启动原有离线项目。正式银行部署应替换成经批准的语音服务及数据处理协议。

## 选择依据

- [edge-tts 项目文档](https://github.com/rany2/edge-tts)：在线音色选择、语速与音调控制、无需单独运行 Edge。
- [Microsoft 普通话音色列表](https://learn.microsoft.com/azure/ai-services/speech-service/language-support?tabs=tts)：普通话神经语音；Azure 与 Edge 可用目录可能不同，须以实测为准。
- [ElevenLabs 中文合成说明](https://elevenlabs.io/docs/overview/capabilities/text-to-speech)：中文及原生口音选择。本次尝试 Jill，但免费生成通道繁忙，没有生成或扣费。
- [SiliconFlow 语音合成](https://docs.siliconflow.cn/docs/userguide/capabilities/text-to-speech)：CosyVoice2 的 anna、claire 等候选，需要 API 账号。本次用户尚无账号，因此不作为当前启用方案。
