# **P04 本地图片识别、人工核对与交易草稿**

## **1. 目标与边界**

### **1.1 业务路径**

- **用途**：在现有页面选择一张图片，本机识别收款人和人民币金额，对照文字位置、置信度和风险提示人工核对，最后仅填入交易草稿。用户自行发送后，才进入既有Supervisor、三色权限、确认/认证、执行器和审计链。
- **需求层级**：OCR属于负责人批准的平台扩展，不增加赛题L1要求。它服务于演示体验，不能把图片中的余额、交易状态或“成功回执”当作真实银行事实。
- **支持范围**：本人演示账户、平台已核验收款联系人、人民币金额。家庭账户、外币兑换、二维码付款、真实卡号导入及票据真伪鉴定不在本批实现范围；遇到账户长号码必须重新选择核验联系人。

## **2. 模型与离线部署**

### **2.1 本地推理资产**

- **引擎**：RapidOCR 3.10.0，ONNX Runtime CPU推理；检测与识别使用随固定wheel提供的PP-OCRv6小模型，方向分类使用ch_ppocr_mobile_v2.0。模型、配置、来源及完整SHA256在`models/ocr/manifest.json`，使用前逐一校验；不下载远程模型，不执行远程代码。
- **依赖**：`requirements-ocr-local.txt`列出获准可选依赖；维护脚本`scripts/prepare_local_ocr.py`生成Windows CPython3.13和Linux CPython3.12的wheel及哈希锁。Windows安装位置`.qa-tools/local-ocr/windows-site`，不改全局Anaconda。其他Python版本不能直接沿用这组wheel。
- **开关**：设置`OCR_ENABLED=1`及`OCR_MODEL_DIR=models/ocr`；默认关闭。依赖/模型缺失、校验不通过或识别失败时明确失败，允许手工填写，不用Mock识别结果冒充实际模型输出。
- **离线包**：联合发行命令与迁移方法见《P03RAG知识库与验收》第9.4节。镜像包含引擎、模型、配置及依赖，Agent容器仅接内部网络。Docker本身须预先安装；源码ZIP不能替代完整离线镜像资产。

### **2.2 本机启动与另一台电脑**

- **当前Windows CPython3.13**：本批资产已经准备，下面只校验、从本地wheel安装及启用。若已安装，可略过安装命令。Python不会自动加载`.env.example`；环境变量必须在启动服务的终端设置。8090端口须空闲，旧服务进程不会自动更新。

```powershell
python scripts/prepare_local_rag.py --verify --reranker --windows
python scripts/prepare_local_ocr.py --verify --windows --install-windows
$env:PYTHONPATH="$PWD\.qa-tools\local-ocr\windows-site"
$env:BANK_AGENT_OFFLINE='1'
$env:RAG_EMBEDDING_BACKEND='local'
$env:RAG_USE_RERANKER='1'
$env:OCR_ENABLED='1'
python app/banking_agent.py
```

- **维护者首次准备**：资产缺失时，在有网且允许下载公开依赖的环境运行`python scripts/prepare_local_rag.py --download --reranker --windows`及`python scripts/prepare_local_ocr.py --download --windows`，再校验/打包；不发送图片、知识资料或用户问题。其他电脑优先使用已验证的完整Docker发行目录，按其中`START_HERE.md`核验与导入，不在断网时执行首次下载。
- **页面操作**：打开`http://127.0.0.1:8090`，点击“读图片，先核对再填写”，选择脱敏PNG/JPEG并同意本机识别；对照框选文字核对收款人和金额，勾选复核后点击“仅填入草稿，暂不办理”。自行发送草稿并经过确认卡才可能办理；真实银行/客服不会因本批变为已接入。

## **3. 接口与数据约束**

### **3.1 图片识别**

- **接口**：POST `/api/v1/ocr/extract`，请求体是PNG/JPEG二进制；可信平台会话提供实际操作人和设备，另须`X-OCR-Consent: yes`。不能通过请求体自报user_id代替认证，家庭代理上下文直接拒绝。
- **边界检查**：不超过2MiB，宽高30—4096且总像素不超过4,000,000；MIME与文件头匹配，Pillow验证结构并实际解码，拒绝动画和解压炸弹。EXIF方向在本地规范化，推理图片元数据清空。单实例一次只识别一张，忙时拒绝，客户端可手工重试。
- **返回**：`draft_id/sha256/width/height/lines/fields/candidates/flags/trace_id`。每行含文字、0—1置信度及四点框；字段附候选来源行。模型置信度不是“正确概率”或付款授权，所有字段一律需要人工核对。
- **金额**：十进制字符串经Decimal转换为整数分，拒绝负数、指数、小数超过两位和超界值。多个金额/收款人冲突时不自动选一个；金额为空由用户核对填写。

### **3.2 人工核对与来源关联**

- **接口**：POST `/api/v1/ocr/review`，字段`draft_id/recipient/amount/reviewed/acknowledged_flags`；`amount`为元的十进制字符串。必须显式`reviewed=true`；有风险提示时额外确认，外币提示不能靠勾选绕过。
- **绑定**：draft与一次性review_token均绑定实际用户、设备，有效期各300秒，容量各32。跨用户、跨设备、过期、重复消费均拒绝。过期后逻辑不可使用；缓存按后续访问清理或进程退出释放，不宣称按时物理擦除内存。
- **填草稿**：review返回`draft_text/amount_cents/recipient/review_token`和`business_executed=false`。页面只填输入框，绝不自动发送。识别到账户长号码时，改开既有转账表单并要求重新选择平台核验账户，不能把同名演示账户默认为图片中的账户。
- **主链关联**：用户自行发送时，原POST `/api/chat`可带`ocr_review_token`。后端一次性核验来源后，仍调用原chat；`ocr.linked`将业务trace关联到识别trace与图片SHA256。来源标记不代表图片/人工修改后的文字已由银行核验。

## **4. 安全、隐私与异常**

### **4.1 不可信输入与生命周期**

- **不外发**：图片、识别文字、用户问法不发送到模型API；图片仅在请求内存中解码推理，不写业务数据库或磁盘。浏览器本地预览可能显示原图，请勿上传含真实隐私的图片；关闭窗口清理文件引用、预览与文字。
- **最小留存**：服务缓存只保存随机ID、操作人/设备、到期时间、图片SHA256、风险标记及来源trace，不保存原图和识别全文。11—19位连续或空格/连字符分隔长号码在识别返回中掩码。此规则不保证覆盖所有敏感信息，用户仍须预先脱敏。
- **注入与泄露**：识别文字经过既有注入过滤；检测到模型密钥形式、验证码/密码等直接拒绝，不生成草稿。页面用textContent展示识别内容，坐标验证为图内有限数值，不能插入HTML/脚本。
- **审计**：`ocr.extracted/ocr.rejected/ocr.reviewed/ocr.linked`记录成功/失败原因、哈希、字段名、标记与trace，不记录原图、完整识别文本和卡号。业务工具的真实结果仍是唯一资金事实来源。

### **4.2 失败行为**

- **拒绝而非补全**：无会话、无同意、超限、格式不符、无文字、输出坐标/置信度不合法、风险输入、过期/重放均明确失败；不让模型猜金额或收款人。
- **回退路径**：依赖、模型或服务不可用时手工输入；用户取消识别窗口不办理业务。低置信度（小于0.90）、缺失与冲突提示要求核对，不能把低置信度静默当确定事实。
- **执行边界**：OCR没有银行工具调用。提取与review不建立待支付业务；chat生成计划仍待原确认卡。红色强认证、熔断、未知交易禁止重试等既有策略不变。

### **5.2 仍需实际使用验证**

- **真实用户**：不同光照、旋转、复杂背景、真实字体及真实票据准确率没有足够样本，不能由一张合成图片证明；后续用授权脱敏图片人工记录字段正确率。
- **辅助设备**：本批浏览器自动化不代替真实NVDA/VoiceOver人工操作；不宣称已完成无障碍设备认证。
- **跨设备**：本机含中文/空格新目录的迁移验收与物理第二台电脑区分；后者仍需负责人拿完整包断网复验。
- **完整压测**：P03本地压力结果不能冒充OCR生产容量或真实银行/IM/IAM压测；本批OCR只设单实例推理并发1和输入预算。
