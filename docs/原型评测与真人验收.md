# 原型评测与真人验收

自动验收对象为当前源码和隔离Mock。本文件不把合成案例、标注工具、硬件模拟或历史成绩称为真实用户验收。

## 固定场景与功能验收

运行`python -B scripts/verify_prototype_matrix.py --output data/verification/<新目录>/matrix.json`，固定12例及分母hash；逐例记录预期与实际动账、失败类型。覆盖A支付恢复、B事实/主张/人工结单分离、C期限/保留额/缺口、注入、撤权及并发重放。所有数据是合成夹具，不对真实银行调用。

## 本地容量与稳定性

新流程：`python -B scripts/prototype_load_test.py --output data/verification/<新目录>/prototype-load.json`。运行前冻结config/prototype_performance_plan.json：并发1/2/4/8，每级8秒、最多64次逻辑操作；持续60秒、目标1次/秒、最多200次。五类实际HTTP流程为服务记录读取、交易异议、资金准备、财务条件DAG后单次付款、人工交接。容量测试只在隔离进程中提高HTTP限流阈值，原默认限流由P10单独测；不是生产容量证明。保留P50/P95/P99、吞吐、超时、限流、未知、采样RSS、逐笔账务和审计校验。阈值预先冻结：错误/未知/超时/重复动账0，P95≤5秒、P99≤10秒，采样RSS≤3GiB、持续阶段增长≤256MiB；不得测后放宽。

既有P10完整组在当前源码重跑，使用config/performance_plan.json：300秒持续负载、默认限流、密码/TOTP、故障、SIGKILL恢复、真实本地RAG向量/重排、索引重建、OCR与音频hash。可选模型依赖沿已批准的.qa-tools/local-ocr/windows-site加载，不安装全局依赖。所有网络仅允许自有loopback，不请求付费云/真实银行。模型与新流程容量分别记录进程资源，不能相加当单一部署上限。

## RAG质量

复用`python -B scripts/rag_evaluation.py --dataset eval/rag_eval_v3.json --output data/verification/<新目录>/rag.json`，词法/本地向量融合/本地独立重排分别报告。冻结资料hash、题目分母与失败题，不能把仍失败的题删掉或把合成题称真人测试。模型清单与知识源版本随报告记录。

## 真人问法、实拍、语音与读屏

复制eval/prototype_user_study_template.json到新的data/verification目录后，由参与者填写。先获得同意，使用p_开头匿名编号；每条至少两名其他匿名复核者，记录提交时间、原型、text/ocr/audio/screen_reader、无隐私自然问法、预期与实际结果。非文本样本加匿名材料hash；本地材料另行妥善保管，导入工具不上传、不执行问法、不认证真实身份或硬件。

运行`python -B scripts/prototype_user_study.py --input <上述文件> --output data/verification/<新目录>/study-report.json`。空样本必须PENDING。失败样本保留，不自评为通过；READY_ATTESTED只表示提供方声明的来源及标注齐全。

人工操作：A核对阻塞与新确认、B核对账单事实/用户异议/人工进度和未退款边界、C核对期限/保留额/不借款。OCR使用无姓名卡号的实拍模糊/倾斜样例，逐字段核对位置与置信度；音频由本人试听后确认，噪声/口音另留实际识别结果，不外发未获授权录音；NVDA/VoiceOver实机检查焦点、朗读、键盘确认和状态变化。真人、真实麦克风/读屏、实际照片没有新证据时保持待验。生产银行/第三方IM/IAM压测和物理第二台电脑另需环境与人工证据。
