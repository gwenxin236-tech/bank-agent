## **1. 本批完成范围**

| 项目 | 实现与边界 | 依据 |

## **3. Windows配置步骤**

### **3.1 轮换密钥**

- 登录SiliconFlow控制台，进入API密钥管理，为本项目创建新密钥；撤销曾发到聊天中的旧密钥。配置成功不证明旧密钥已撤销，本项目无法代为核实撤销情况。
- 密钥只放本机环境变量或受控密钥管理，不写入项目、文档、截图、PR、终端命令历史或验收记录。不要再次发送到聊天。
- 操作入口参考[官方快速开始](https://docs.siliconflow.cn/docs/userguide/quickstart)。

### **3.2 在Windows用户变量中保存**

- 按`Win+R`，输入`sysdm.cpl`并回车；打开“高级 → 环境变量”。
- 在上半部分“用户变量”依次新建或编辑下表变量；密钥值在本机界面填写。所有确认窗口保存后，新开PowerShell。无需管理员权限，也无需创建`.env`。

| 变量 | 值或说明 |
|---|---|
| LLM_API_KEY | 刚创建的新密钥，本文件不包含实际值 |
| LLM_PROVIDER | siliconflow |
| LLM_BASE_URL | https://api.siliconflow.cn/v1 |
| LLM_MODEL | Qwen/Qwen3.5-35B-A3B |
| LLM_TIMEOUT_SECONDS | 20 |
| LLM_MAX_OUTPUT_TOKENS | 512，可省略采用默认值 |
| LLM_CALLS_PER_MINUTE | 20，可省略采用默认值 |
| LLM_MAX_CONCURRENT | 2，可省略采用默认值 |
| BANK_AGENT_OFFLINE | 真实API专项设0；离线回归设1 |
| VOICE_ENABLED | 0，本批不验收语音 |

不要把末尾说明文字或中文标点复制进URL；地址不包含`/chat/completions`。适配器自行追加此路径。Python本身不会自动读取`.env`，`.env.example`只提供说明。[官方对话接口](https://docs.siliconflow.cn/docs/api/chat-completions-post)。

### **3.3 确认当前终端环境**

- 在新PowerShell中执行下列安全检查；第一项应为`True`，其他三项应与表中一致。不要直接输出`$env:LLM_API_KEY`。

```powershell
[bool]$env:LLM_API_KEY
$env:LLM_PROVIDER
$env:LLM_MODEL
$env:LLM_BASE_URL
```

- 如果之前仅用`$env:变量名=...`配置，它只在当前终端及其子进程生效。可在那个已配置的终端执行以下命令，将已有值保存到用户变量；它不打印密钥。

```powershell
'LLM_API_KEY','LLM_PROVIDER','LLM_MODEL','LLM_BASE_URL','LLM_TIMEOUT_SECONDS' |
    ForEach-Object {
        $value = [Environment]::GetEnvironmentVariable($_, 'Process')
        if ($value) { [Environment]::SetEnvironmentVariable($_, $value, 'User') }
    }
```

- 已经运行的应用不会自动继承新用户变量，可重启服务/终端；本批验收脚本也支持显式`--load-user-env`读取固定白名单。沙箱中的用户注册表可能与本人桌面会话不同，需在本人终端执行验收。脚本不会枚举其他注册表值，不读取PATH或数据库路径，也不保存密钥。

## **4. 运行和重复验收**

以下命令在项目根目录`C:/Users/gwx/Desktop/bank_agent/银行ai智能体app`执行。`python`应指向Python 3；本机本批实际使用`D:/anaconda/python.exe`。模型验收需要外网和有效额度；离线演示不需要。

### **4.1 查询账号可用模型**

- 模型列表请求只做带认证的GET，不发送聊天推理；列表可见不能证明JSON模式、业务准确率或图像能力可用。[官方模型列表接口](https://docs.siliconflow.cn/docs/api/models-get)。

```powershell
python scripts/verify_llm.py --load-user-env --list-models --output data/verification/p02-local/models.json
```

### **4.2 一次真实API主链验收**

- 推荐临时模拟银行模式：只发送固定虚构短句“请查询我的账户余额”，不读取日常演示库，不确认转账、不取消订阅。该请求会产生少量模型费用；审计记录和账号数据只在临时库中，报告保留受控指标与trace。
- `PASS`须同时满足：本次确实采用模型结果、余额工具成功、plan/trace一致、审计链有效、余额、订阅与核心交易快照未变。规则回退成功仍算模型验收`FAIL`。

```powershell
python scripts/verify_llm.py --load-user-env --isolated-model --output data/verification/p02-local/live-model.json
```

- 如果要检查自己已启动的服务，应在配置了环境的终端运行`python app/banking_agent.py`，再从另一个终端执行下列命令。此模式会在该服务数据库中写入正常审计记录，适合显式指定的演示服务；默认地址仅接受回环HTTP，不允许把演示token发到外部地址。

```powershell
python scripts/verify_llm.py --url http://127.0.0.1:8090
```

### **4.3 离线完整回归**

- 未启用模型变量的独立终端执行`python scripts/browser_qa.py --full`。该脚本准备临时数据库并验证日常数据库哈希不变；须有本地QA所需Node/Playwright/浏览器工具，不需要模型API。
- `data/verification/`为本地验收记录，未自动随源码发布；公开快照见`docs/验收摘要.json`。历史数字不能替代对当前代码的重新验收。

## **5. 请求边界与故障排查**

| 设置/情况 | 行为与限制 |
|---|---|
| API地址 | SiliconFlow固定HTTPS官方域名及`/v1`；其他兼容网关需显式配置HTTPS。HTTP仅允许回环测试；禁URL内凭据、查询串、片段和重定向 |
| 超时 | 默认8秒，可配置为`(0,60]`秒；本次在线验收采用用户设置。是urllib连接/读取超时，不声称覆盖完整业务的硬实时截止 |
| 输出 | 默认512，配置范围1–2048输出tokens；非流式、JSON对象模式；SiliconFlow本阶段关闭thinking；不通过追加重试或切换模型掩盖失败 |
| 调用限额 | 默认同一客户端实例每滚动60秒20次、同时2次；失败请求计数。允许范围分别1–600、1–16；超限立即回退。不是跨进程、跨实例、跨账号配额，也不等于供应商消费封顶 |
| 输入隐私 | 仅文本，不附账户余额或工具结果；明显手机号、长数字卡号/证件号、密钥及部分密码/OTP表达阻止外发。不是完整DLP，分隔符/新表达/编码可能未覆盖，真实敏感数据仍需专门脱敏与同意流程 |
| 响应 | 最多65536字节；拒重复JSON键、NaN/Infinity、截断/工具调用结果、非法意图、金额布尔/浮点/字符串、嵌套冒充文本。实体金额必须为正整数分，未知权限字段不能进入工具协议 |
| 可观测性 | 保留source、attempted、accepted、reason、耗时、HTTP状态、限定usage整数；不记录请求正文、原始模型输出、HTTP错误体或异常文本 |

| reason / 状态 | 优先检查 |
|---|---|
| disabled / offline | 是否配置密钥与完整模型ID；离线开关是否为1；服务进程是否重启 |
| invalid_config | URL末尾及域名、数字配置范围；不要把Base URL写成完整chat端点 |
| privacy_blocked / invalid_input | 输入隐私与2000字符限制；不建议通过拆分敏感信息绕过检查 |
| http_error，401/403 | 在平台核查密钥、模型权限和账户；不要将错误体或密钥贴到公开日志 |
| http_error，429 | 检查供应商配额、并发和调用频率；本适配器不自动重试 |
| timeout / network_error | 网络/代理/证书/平台状态及合理超时；请求失败会回退规则，不代表真实模型通过 |
| incomplete_response / invalid_json / schema_rejected | 模型JSON兼容、输出上限和已知实体类型；不可直接使用未校验的输出 |
| rate_limited / concurrency_limit | 本实例限额已触发；等待窗口或控制并发，不以新建无限客户端绕过预算 |
